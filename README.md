# MassGlamour

I spent a long time looking for something to mass apply Glamourer designs to characters and nothing came of it (the Glamourer devs seem very against implementing it for some reason too), thus I decided to throw this together for myself.
This is vibe-coded garbage because I couldn't be bothered to learn how to make a plugin or read all the required APIs, but I haven't run into any bugs besides some NPC animations breaking, which already happens with manually using Glamourer.

 Glamourer designs, Customize+ profiles, and Penumbra collections to currently loaded characters using configurable filters.

## Dalamud installation

Add this repository URL in Dalamud's custom plugin repositories:

`https://raw.githubusercontent.com/badstupid6/MassGlamourPlugin/main/repo.json`
